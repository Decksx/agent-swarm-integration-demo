# agent-swarm integration demo

A throwaway repository, created 2026-09-11 as the target for the controller's
first end-to-end author -> review -> integration run.

Nothing here is production. It exists so that a merge performed by the
integrator lands somewhere real without landing anywhere that matters.

## Layout

- `notes/` holds whatever a demonstration task is asked to write.

## Provenance

Created for the controller-native demonstration. It shares no history with the
`greeting` repository used for the MVP3 rejection cycle, and no controller
events have been fabricated for it.
